Prompt 4 — FR-17 State & Lifecycle (PROMPT)

Phân tích chuỗi chuyển đổi trạng thái (State Transition) cho vòng đời của Coupon trong hệ thống:
DRAFT / INIT -> ACTIVE (POST Created) -> USAGE DECREMENT -> EXPIRED / DELETED (DELETE / Expiry).
Liệt kê các kịch bản kiểm thử tương tác chuỗi nhiều API liên tiếp.
